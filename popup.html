Dictionary key (한국어기초사전)

A free key from the National Institute of Korean Language lets the word card show the part of speech, vocabulary level (어휘등급) and numbered meanings. You only need to do this once.

  1. Open the key page (한국어기초사전 Open API). The site is in Korean; use your browser's translate option if you need it.
  2. Sign up (an email address is enough) and log in.
  3. Apply for an API key (인증키) for the dictionary's Open API. A short description such as "personal Korean study" is fine.
  4. Copy the key it gives you.
  5. Paste it below and press Save & test. You should see "Key works".

The page layout may change. If a step looks different, look for the Open API / 오픈 API section and the key request (인증키 신청). If the test says the key was refused, wait a few minutes after getting it and try again.
